## 繁体目录（zh-tw）说明

繁体内容为 **OpenCC 机器转繁（s2tw 台湾正体）+ 勘误规则** 的产物：

- 文本**以简体（zh-cn）为准**；
- **繁体 PR 原则上不收**（会与转换管线冲突）；发现繁体错字请[开 issue](https://github.com/xianmi-lib/xianmi-texts/issues)，我们会在勘误规则中修正后重新转换。

欢迎对 `zh-cn` 目录提交 PR 或 issue：错字、标点、段落、篇章归属等问题均可。请尽量附上篇目路径与原文位置。提 PR 前请先读 [CONTRIBUTING.md](CONTRIBUTING.md)（含维护者回植主仓的闭环要求）。
