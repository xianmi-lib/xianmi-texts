# 顯密文庫 · 公開文本倉（xianmi-texts）

**語言 / Language**：[简体中文](README.md) | 繁體中文

[顯密文庫](https://www.xianmi.co/zh-tw/) 的公開文本倉庫，作為社區協作入口，從少到多逐步開放。

**首發收錄：`p05` 佛教經典 · 現代漢語譯文（全量）**，後續將逐步開放更多部類。

## 目錄結構

```
zh-cn/p05/   簡體（1,819 個文件，含欄目索引頁）
zh-tw/p05/   繁體（與簡體鏡像同構）
```

文件為 Markdown / MDX（Astro Starlight 組件語法原樣保留），路徑與顯密文庫主站一一對應。

## 本倉繁體內容的說明

繁體內容為 **OpenCC 機器轉繁（s2tw 台灣正體）+ 勘誤規則** 的產物：

- 文本**以簡體（zh-cn）為準**；
- **繁體 PR 原則上不收**（會與轉換管線衝突）；發現繁體錯字請[開 issue](https://github.com/xianmi-lib/xianmi-texts/issues)，我們會在勘誤規則中修正後重新轉換。

## 勘誤協作

歡迎對 `zh-cn` 目錄提交 PR 或 issue：錯字、標點、段落、篇章歸屬等問題均可。請儘量附上篇目路徑與原文位置。提 PR 前請先讀 [CONTRIBUTING.zh-TW.md](CONTRIBUTING.zh-TW.md)（含維護者回植主倉的閉環要求）。

## English Summary

**xianmi-texts** is the public text repository of [Xianmi Library](https://www.xianmi.co/) (顯密文庫), a free Chinese Buddhist digital library. Debut collection: `p05` Buddhist Sutras in Modern Chinese Translation (complete, 1,819 files). Original sutra texts are in the public domain; our editorial work, collation, and modern Chinese translations are released under [CC0 1.0](LICENSE). Content is in Chinese: `zh-cn/` (Simplified) is canonical, and `zh-tw/` (Traditional) is machine-converted — please submit PRs against `zh-cn` only. See the Chinese text above for details, or open an issue.
